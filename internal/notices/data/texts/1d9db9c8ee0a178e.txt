tuiffects is a Go port of ttfx, which is itself a port of TerminalTextEffects.

The chain, oldest first:

    TerminalTextEffects (TTE)
    https://github.com/ChrisBuilds/terminaltexteffects
    MIT License, Copyright (c) 2023 ChrisBuilds

    ttfx (Rust port of TTE)
    https://github.com/omacom-io/ttfx
    MIT License, Copyright (c) 2026 37signals / omacom-io

    tuiffects (this package, Go port of ttfx)
    https://github.com/Gaurav-Gosain/tuiffects
    MIT License, Copyright (c) 2026 Gaurav Gosain

Every effect here, and the architecture of the animation engine that runs
them, are ChrisBuilds' design. ttfx translated that work to Rust and says
plainly that it originates none of the art. This package translates ttfx to
Go and originates none of it either.

What was deliberately NOT carried over:

  * ttfx reproduces the Python original byte for byte, which requires a
    Mersenne Twister clone and a parity harness. This port makes no parity
    claim, so it uses Go's own generator and ships no parity suite. The same
    effect will not produce the same frames here as it does there.
  * The command-line interface, the tty writer, and resize handling. This
    package renders into a host program's screen, not into a terminal it
    owns.
  * Two of ttfx's thirty-seven effects, `beams` and `colorshift`. The other
    thirty-five are all here.
  * The AldousBroder spanning tree, which ttfx also leaves out because no
    shipped effect uses it.

Rounding quirks that ARE carried over, because they change how the effects
look and removing them would silently retune every one of them: half-to-even
rounding on coordinates, integer floor division on gradient channel steps,
and the bezier arc-length estimate that stops at t=0.9.

Where this port deviates on purpose, it is because upstream is written for
piped text and this is written for a screen that already exists. Each such
deviation is commented where it is made, and each is scoped to the
input-colour policy so the default behaviour stays upstream's.

If you enjoy these effects, the credit belongs upstream, with ChrisBuilds.
